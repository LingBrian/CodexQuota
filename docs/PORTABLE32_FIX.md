# v0.0.32 便携版账号修复

本机旧配置 quotaCommand=null；v0.0.31 查询和账号操作分别将其作为未配置错误，虽然随包 CLI 实际存在。修复为统一回退 codex-switch，并优先解析主程序同目录的 CLI。保留显式自定义路径和原配置文件。

账号页之前没有本机文件发现功能。本版在页面加载时扫描 CODEX_HOME/auth.json 与 USERPROFILE/.codex/auth.json，去重且只返回路径和建议别名，不返回认证数据、不递归扫描其他目录、不自动导入。

导入路径支持空白、Windows 复制路径引号和 auth.json 所在目录。失败信息按上游阶段分类，避免将原始凭据或服务器响应输出到界面。导入失败时关闭确认框、清除已经消费的预览，重新预览后才能再次提交。

验证：19 项前端测试通过；38 项 Rust 全量测试及新增空白/null 配置专项测试通过，1 项真实登录测试默认忽略。类型检查、构建、Clippy 通过。

`reports/portable32-null-cli/runtime-smoke.json`：正式便携包在 quotaCommand=null 下真实启动通过；查询成功、账号列表 1 项、5h/7d 额度、导入预览、托盘和覆盖层均通过。

`reports/account-fixture-yDXgUh/result.json`：随包 CLI 使用合成凭据与隔离目录完成同一账号导入去重，未轮换凭据；重命名、切换、归档、当前账号删除保护通过。

全新账号联网验证仍依赖实际凭据及网络，不能由合成凭据测试证明。未为了测试而切换或导入用户的真实账号。
