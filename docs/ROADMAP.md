# CodexQuota 路线图：v0.0.0 → v0.0.30

## 版本规则

- `v0.0.0` 是可安装的基线；M1–M30 分别发布为 `v0.0.1`–`v0.0.30`。
- 每个 M 都必须包含：可运行功能、自动化测试、变更日志、升级说明和验收记录。
- 未确认的上游 JSON 协议不得进入生产解析器；不得用模拟额度替代真实数据。

## 发布门禁

每个 M 合并前必须执行 `npm run check`、`npm test`、`npm run build`、`cargo fmt --check`、`cargo test`、`cargo clippy -- -D warnings`。M13 必须验证动态图标的两条进度条分别映射 5h/7d，且缺失数据不画作满格。M18–M22 额外要求在 Windows 10/11 的物理或虚拟机上记录手工验证结果；M30 额外要求安装/卸载、升级、Explorer 重启、多显示器与签名状态检查。
