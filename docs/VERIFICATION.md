## 每阶段升级

所有版本沿用设置 schema 2，新增字段有兼容默认值；凭据始终由独立的上游 CLI 管理。升级前通过托盘退出旧进程，再安装/运行新版本。新版本不得删除现有 Codex 登录文件。安装包、实际安装和卸载是不同证据，分别记录。
