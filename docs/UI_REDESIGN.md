# v0.0.31 界面改版

## 设计范围

以石墨灰／浅灰背景和薄荷色为默认强调色，使用原生字体，不下载外部字体。保留既有用户强调色。六个页面共用导航、连接状态、标题、控件、表格、对话框与响应式规则。

仪表盘不画模拟趋势或捏造历史。仅呈现真实剩余额度、重置时间、当前账号、同步时间及来源。未知数据使用未知态；低于 20% 独立着色。任务栏 5h 与 7d 各自独立，缓存有提示，越界数据不会变成满额度。

## 任务栏预设

| 预设 | 默认大小 | 内容 |
|---|---|---|
| 轻巧胶囊 | 260×38 | 标签、百分比 |
| 双条进度 | 300×46 | 标签、百分比、两条独立进度条 |
| 透明文字 | 240×32 | 无背景的标签与百分比 |

应用预设会修改外观与尺寸，但不改变显示器、边缘偏移、鼠标穿透、账号或凭据。三种样式均可继续微调。屏幕过窄／窗口过矮时降低信息密度；保持右键托盘入口，不抢焦点。

## 验证边界

- 前端回归包含预设保存、保留位置偏好、双指标隐藏、无效值、缓存、显示已用比例与重置过期状态。
- 桌面自检进一步覆盖六个页面横向溢出、胶囊文本边界、实际额度、双进度条、原生工作区、离屏恢复与不激活行为。
- 自动布局检查不等同于截图审美验收。Windows computer-use 和浏览器工具本轮都报告 `helper_unknown_error: setup refresh had errors`，不声称取得了新版截图。
- 旧版长稳进程与新版候选验证隔离；旧版结果不能证明新版稳定性。正式升级运行新版前应退出旧版，原有凭据不应被清除。

- 最终完整门禁：18 项前端测试、36 项 Rust 测试通过；另有 1 项必须显式指定真实 CLI 的测试默认忽略，未把忽略计为通过。类型、生产前端构建、fmt 和全目标 clippy 均通过。

- `reports/UI31-release-isolated-layout/runtime-smoke.json`：最终源码的独立身份优化验证程序运行通过，包括新版双色托盘初始化、真实 5h／7d、两项进度、离屏恢复、穿透切换与不激活。
